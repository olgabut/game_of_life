# Game of Life

The Game of Life was created by British mathematician John Horton Conway in 1970.

The idea: a grid where every cell can be either alive or dead.

Each cell has eight neighbours. Its state in the next generation depends on how many of these neighbours are alive.

**Rules:**
* A live cell with fewer than two live neighbours dies.
* A live cell with two or three live neighbours stays alive.
* A live cell with more than three live neighbours dies.

A dead cell with exactly three live neighbours becomes alive.

The player only chooses the starting position of the live cells. This is called the first generation. After that, everything happens automatically.

## The webpage allows:

- Watch how the cells change from one generation to the next.
